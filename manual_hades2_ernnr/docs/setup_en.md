# Hades 2 Manual Randomizer Setup Guide

## Required Software

- Hades 2
- Archipelago Launcher
- `manual_hades2_ernnr.apworld`

## Installation Procedures

The following instructions are necessary to Generate an Archipelago with the Hades 2 Manual. This only needs to be done by 1 player/host.

1. See https://archipelago.gg/tutorial/ for instructions on how to install and setup the Archipelago Launcher.
1. See https://github.com/ernnr/Hades-2-Manual-Archipelago/releases to download the latest version of the `manual_hades2_ernnr.apworld` and (optionally) the example `Manual_Hades2_ernnr.yaml`.
1. In the Archipelago Launcher, select the "Install APWorld" tool and select the previously downloaded `manual_hades2_ernnr.apworld`.
1. Either customize the previously downloaded example yaml, or use the "Generate Template Options" tool in the Archipelago Launcher to generate a new yaml. Once the yaml is customized, move it into the `-/Archipelago/Players` folder along with any other yamls for the MultiWorld.
1. In the Archipelago Launcher, select the "Generate" tool. The `-/Archipelago/output` folder will contain a newly generated `AP_#####.zip` file containing the MultiWorld details.

## Joining a MultiWorld Game

The MultiWorld Game can either be hosted locally by using the "Host" option in the Archipelago Launcher or by uploading the `AP_#####.zip` file to https://archipelago.gg/uploads. Once hosted, the server and port along with slot information can be shared with the players.

The MutltiWorld Game can be joined using the "Manual Client" found in the Archipelago Launcher. Then enter the server and port information along with the information for the specific slot.

Hades 2 can be launched like normal and you can use either a completed save file or the custom save file included with the manual.
